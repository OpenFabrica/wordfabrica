# 网页编辑使用说明

网页顶部的 **语言 / Language** 菜单可选择 **简体中文** 或 **English**，无需刷新。选择会保存在当前浏览器，重新打开仍然生效；正文不会被翻译或修改。

1. 打开服务器地址（本地默认为 `http://127.0.0.1:8771/`），直接在纸张区域输入。
2. 顶部文本框可以修改文档名称。工具栏提供字体、段落、表格等原有编辑功能。
3. AutoSave 开启时，停止输入约 1.5 秒后自动保存。也可点击 **Save to server**、原有保存按钮，或按 `Ctrl+S` / macOS `Cmd+S`。
4. 看到 **Saved to server** 和版本号后，内容才已被服务器确认。保存后的地址含文档 ID，可收藏并重新打开。
5. 点击 **Documents** 打开服务端文档列表；点击 **New document** 新建文档。当前内容未保存时先完成保存。
6. File → Open 可导入本地 DOCX、ODT、RTF、TXT 等现有支持的格式；它会作为新的服务端文档保存。
7. **Download DOCX** 或 File 的导出功能下载本地副本。下载不会替代服务端保存。

发生网络错误时，当前内容仍在页面中，显示 **Not saved**。连接恢复后点击 **Retry**；也可先下载副本。
不要在未保存时强制关闭标签页。浏览器可能显示离开提醒，但本版没有离线草稿恢复。

多个窗口编辑同一文档时，先保存的版本保留。后保存的窗口收到冲突提示：

- **Save as new copy**：把当前编辑保存为另一份文档，得到新的链接。
- **Reload server version…**：确认放弃本地修改后打开服务器最新版本。需要保留时先下载副本。

单份请求上限 16 MiB（包含图片），标题最多 200 字符。服务器重启后文档保留；所有访问同一服务的用户共享文档列表。
这是一套轻量存储方案，暂不支持多人实时合并编辑或历史版本恢复。

## 中文字体

“开始 → 字体”中可以选择 **Noto Sans CJK SC**（中文无衬线字体）。选中文字后切换字体，保存后重新打开仍保持字体名称。
服务端配置的其他字体也会自动出现在同一列表中，例如 **Noto Serif CJK SC**（中文衬线字体）。
字体由服务器下载，不要求电脑安装；字体名称保存在文档中，DOCX 不内嵌字体文件。
如果其他软件或部署没有该字体，会按其字体回退规则显示。管理员扩展字体后，请先保存文档再刷新网页。
启动时出现“部分服务器字体未能加载”表示当前使用可用字体回退，排版可能不同；保存后刷新可重试。
管理员操作见 [服务端字体扩展](web-fonts.md)。

## 宋体、黑体与文档语言

“开始 → 字体”可直接选 **宋体**、**黑体**；网页用服务端/内置开放中文字体兼容显示，保存和导出保留所选字体名称。
点击窗口底部的语言标签，选择 **中文（中国）** 或 **English (United States)**，会应用到整篇文档，并随文档保存；可撤销。
“审阅 → 语言”提供同一入口。它与左上角的界面语言独立，不会翻译已有正文。
